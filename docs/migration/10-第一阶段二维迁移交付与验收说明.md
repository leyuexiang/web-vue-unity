## 启动及复验

依赖 Node.js 22.12 或以上、pnpm 10.34.6。已有 `.env.development.local` 时先保留；首次配置参照根目录 `.env.example` 填写当前环境地址，不从来源复制真实账号密码。

```powershell
pnpm install
pnpm dev
```

示例路径：`http://localhost:5180/threeWeb/`。首页为场景列表；场景编辑路径为 `/threeWeb/sceneEdit?id=实际场景编号`。真实页面继续使用来源登录与编辑锁协议，不提供绕过鉴权的业务入口。

```powershell
pnpm type-check
pnpm test
pnpm media:test
pnpm audit:frontend
pnpm build
```

保持开发服务运行后复验隔离浏览器：

```powershell
$env:TWOD_SMOKE_FULL='1'
$env:TWOD_SMOKE_REPORT='docs/migration/09-二维浏览器验收结果.json'
pnpm test:browser:2d
```

使用其他基础路径时设置 `TWOD_SMOKE_BASE_URL`。脚本通过真实页面模块验证配置和宿主，针对开发服务器执行；生产构建通过不等于生产站点部署验收完成。测试不会保存登录凭据。

`scripts/migrateFrontendSource.mjs` 是首次复制工具，基线存在时默认拒绝运行。后续请在适配后的目标代码上修复，不能使用其 `--refresh` 覆盖本次改造。边界审计的 `--prune` 仅清理来源基线内、未修改且不再被应用或测试引用的代码。
