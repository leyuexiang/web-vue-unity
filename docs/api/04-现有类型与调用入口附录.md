# 现有类型与调用入口附录

日期：2026-10-20。本文为代码字段快照，配合前三份说明使用，不是新的接口实现。

类型脚本（TypeScript）记法：`?` 表示当前前端允许省略，`|` 表示联合类型，`[]` 表示数组，`Record<K,V>` 表示键值映射，`extends` 表示继承已有字段。可选性不覆盖正文明确的业务必填；`unknown` 或普通对象表示保留扩展，不能理解为任意值均合法。编号的 `string | number` 是历史兼容，**新后端编号统一返回字符串**。

每节独立于对应源文件作用域。同名 `SceneObject/SceneDefinition` 来自正式领域与旧 Unity 投影时不能混用。纯前端缓存、索引、状态、端口或控制器类型不应直接建成后端接口。接口方法和地址以前三份契约表为准。

服务端不需要照抄前端类；应实现正文的结构与校验，并保全组件私有 JSON。下列代码中的注释沿用当前实现，表示来源上下文，不构成执行指令。
