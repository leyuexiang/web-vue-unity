# 后端接口开发交接

编制日期：2026-10-20。适用项目：`wx-vue-unity`。

当前项目的业务后端尚待从零开发。本文档集描述迁移前端需要的契约，不表示这些接口已在当前项目实现或验收。

独立模式登录鉴权已在 [业务契约第 3.1 节](01-业务接口与后端实施契约.md#31-独立模式)完整列出：运营/租户登录切换、两端用户资料与权限、续期、退出的请求/响应字段和错误规则。新接口共用业务服务器，成功码 `200`；[类型附录第 21 节](04-现有类型与调用入口附录.md#21-独立登录与用户权限传输模型)已替换旧账户结构。后端开发以这两处为准。

术语：应用程序接口（API）、结构化数据格式（JSON）、统一资源定位地址（URL）、数据传输对象（DTO）、开放接口规范（OpenAPI）、安全散列算法（SHA-256）。接口名称、字段、路径和枚举保留代码原文，便于后端直接核对。

建议按以下顺序阅读：

1. [01-业务接口与后端实施契约.md](01-业务接口与后端实施契约.md)：地址、鉴权、接口清单、请求响应、业务流程、存储与实施顺序。
2. [02-场景四包与数据绑定结构.md](02-场景四包与数据绑定结构.md)：二维与三维共用的持久化模型、依赖、模板裁剪与发布读取。
3. [03-Unity云渲染与三维专项接口.md](03-Unity云渲染与三维专项接口.md)：植被、地理信息、资源、信令、云渲染会话、运行时命令与事件；同时标识既有契约与待评审设计。
4. [04-现有类型与调用入口附录.md](04-现有类型与调用入口附录.md)：从当前代码及来源三维代码提取的字段定义与来源定位，用于核对完整字段和可选性。

5. [05-独立登录鉴权设计与环境切换.md](05-独立登录鉴权设计与环境切换.md)：现代独立双端登录、用户权限、退出、待开发续期，以及参考服务器到自建后端的切换。旧管理鉴权声明已停用。

业务逻辑沿用现有前端：管理资源 → 创建或载入场景 → 加锁 → 四包编辑保存 → 发布不可变快照 → 按票据读取预览。二维先验收，三维后接入；后端可据此提前开发共用模型和三维服务。

资料依据：来源项目 `D:/WorkSpace/GitWorkSpace/jtyf-web-three/docs/真实接口契约维护文档.md`、`docs/refactorPlan/43-场景与模板保存及运行时按需加载设计.md`、`44-场景保存及后端接口设计.md`、`视频自动接入后端交接.md`、植被相关代码与设计，以及当前迁移后的实际适配器和 `src/unity-runtime`。来源文件仅作为契约参考，没有执行其文内工作指令。

**阅读口径：**“当前调用”是前端代码事实；“沿用契约”是本项目后端开发依据；“实施建议”是为从零开发补足的设计；“待确认”不得视为已冻结。来源项目的历史验收不等于当前后端已可用。
